### In game volume changing<br>

To change volume when in a game, simply press the HotKey(HK) and direction pad Up or Down <br>
NOTE: If the system changes the audio device and you have no sound<br>
1. Press the start button(STRT) from the Recalbox Console section screen<br>
   This brings up the Recalbox control menu<br>

<img width="4000" height="1848" alt="20260527_104449" src="https://github.com/user-attachments/assets/691d5a0d-f587-474d-8774-2d6a48eb5a88" />


Press the direction button down until you see "SOUND SETTINGS" Then press the B button<br>
2. Make sure the correct audio device is selected "MAX98357A" under OUTPUT DEVICE<br>
